# Amazon-Sales-Dashboard

## Project Overview
An interactive Amazon Sales Dashboard created using Microsoft Excel
to analyze sales performance and identify key business trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas

## Dashboard Features
- Total Sales
- Sales by Category
- Sales by Product
- Sales by Location
- Payment Method Analysis
- Order Status Analysis
- Interactive Slicers
